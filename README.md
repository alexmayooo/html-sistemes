# PlayZone

PlayZone es una página web de juegos online gratis creada con HTML y CSS. El proyecto presenta un portal visual moderno para explorar categorías, juegos populares, novedades y un catálogo completo de propuestas de entretenimiento, todo pensado para navegar directamente desde el navegador sin necesidad de frameworks ni backend.

## ¿De qué trata este proyecto?

La web simula una plataforma de juegos con:

- Cabecera con navegación y buscador
- Hero section con llamada a la acción
- Secciones de ventajas y categorías
- Tarjetas de juegos populares y recientes
- Catálogo completo por géneros
- Footer con información y enlaces
- Diseño responsive y visualmente atractivo

## Tecnologías utilizadas

- HTML5
- CSS3
- Diseño completamente estático
- Sin dependencias externas

## Cómo ejecutar el proyecto

1. Clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. Si prefieres servirlo localmente, puedes ejecutar:

```bash
python -m http.server 8000
```

Luego accede a:

```text
http://localhost:8000
```

## Objetivo del proyecto

Este repositorio es una práctica de maquetación web enfocada en crear una interfaz de sitio de videojuegos con un estilo moderno, oscuro y dinámico, ideal para mostrar contenido de entretenimiento y navegación por categorías.
